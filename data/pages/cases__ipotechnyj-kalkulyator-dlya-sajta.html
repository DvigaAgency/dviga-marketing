О заказчике

DNS Сити — жилой комплекс в пригороде Владивостока. Ранее нами был разработан сайт проекта на платформе Tilda, который является основным инструментом продаж квартир: здесь потенциальный покупатель смотрит планировки, узнаёт об инфраструктуре и принимает решение о покупке. Подробнее о разработке сайта проекта можно почитать в кейсе «Создание сайта для города-спутника DNS».

Отзыв

Задача от клиента

Клиенту было важно увеличить число целевых обращений с сайта. Поэтому появилась идея реализовать на сайте ипотечный калькулятор, который в режиме реального времени показывал бы предложения от реальных банков с актуальными ипотечными ставками и с учётом льготных условий — Дальневосточной, Семейной, IT и Военной ипотеки, позволял бы выбрать понравившуюся ипотечную программу и направить заявку в отдел продаж. Важно было, чтобы заявки автоматически поступали в нужную воронку amoCRM на стороне клиента.

Визуально калькулятор должен был органично вписаться в дизайн сайта: фирменные цвета, шрифты и стиль DNS Сити — без ощущения «вставного» стороннего виджета.

Подход к решению задачи

У клиента была активная подписка на платформу «Движ», которая предоставляет различные цифровые сервисы для застройщика, в том числе готовый ипотечный калькулятор, интегрированный с банками-партнёрами. Так как калькулятор должен был вписаться в дизайн сайта и иметь некоторые функциональные особенности, которые хотел реализовать клиент, мы не могли взять готовый виджет, который предлагает платформа. Было принято решение «подружить» клиентскую часть реализованную на Tilda и API платформы «Движ» для получения актуальной информации об ипотечных программах.

Архитектура интеграции

Прямое обращение к API Движ со страницы сайта было невозможно по нескольким причинам:

  • Во-первых, API Движ использует JWT-авторизацию через GraphQL. Хранить токен в JavaScript-коде страницы нельзя: любой пользователь найдёт его в инструментах разработчика браузера и сможет использовать от имени клиента. Следовательно, авторизация должна быть только на серверной стороне.
  • Во-вторых, политика кросс-доменного взаимодействия не позволяет браузеру напрямую запрашивать данные с серверов другого домена. Нужен промежуточный сервер, который принимает запрос от сайта, добавляет авторизацию и обращается к API Движ.

Чтобы обойти ограничения, была реализована система, состоящая из трёх частей: графический интерфейс с ипотечным калькулятором на сайте на Tilda, сервер на Node. js, API Движ для получения актуальной информации об ипотечных программах.

Для реализации серверной части была выбрана технология Node. js + Express. Она выполняет роль обратного прокси: принимает запросы от сайта, добавляет JWT-токен и отправляет их в API «Движ». Токен хранится в .env на сервере и недоступен извне.

Для соединения между сайтом и сервером выбрали протокол HTTPS. Для быстрого получения SSL-сертификата использовали sslip. io — сервис, который автоматически предоставляет HTTPS-доступ к любому IP-адресу. Адрес вида 193.238.134.76.sslip.io получает валидный сертификат без дополнительной настройки.

Разработка визуальной части калькулятора на Tilda

Чтобы сделать калькулятор на сайте ДНС Сити максимально удобным для пользователей, изучили визуальные особенности подобных калькуляторов на сайтах жилых комплексов по всей России. Собрали пул лучших интерфейсных решений — что работает удобно, что раздражает, какие параметры стоит вынести на передний план.
На основе этого анализа и брендбука DNS Сити нарисовали дизайн-макет в Figma. Учитывали не только цвета и шрифты, но и общее оформление сайта: стиль карточек, принципы сетки, логику расположения элементов.

Особенности интерфейса калькулятора

В интерфейсе пользователь вводит базовые параметры:
  • стоимость объекта
  • размер первоначального взноса
  • желаемый срок кредита
А также может указать дополнительные условия, которые напрямую влияют на результат подбора:
  • наличие жилищного сертификата
  • материнский капитал
  • предпочтительную программу ипотеки

Все эти параметры передаются в API Движ и влияют на то, какие банковские предложения отобразятся в результатах.

Чтобы пользователю были понятны особенности разных типов ипотечных программ, добавили их условия и ограничения в интерфейс калькулятора. Покупатель сразу понимает, подходит ли ему та или иная программа, не уходя с сайта для поиска информации.

Сборка в Tilda

После согласования дизайна перешли к вёрстке. Калькулятор собрали в Zero-блоке Tilda с использованием стандартного элемента «форма». С помощью дополнительных CSS стилей на странице скорректировали верстку некоторых стандартных элементов формы, чтобы привести их к общему стилю сайта.

Итоговый процесс работы калькулятора по шагам

Полная цепочка от действия пользователя до отображения результата:

Шаг 1. Загрузка страницы на сайте

Скрипт на странице автоматически отправляет запрос с параметрами на сервер, которые установлены по умолчанию. Пользователь сразу видит банковские предложения — не пустую форму.

Шаг 2. Ввод параметров

Пользователь задаёт стоимость объекта, размер первоначального взноса, срок кредита и дополнительные условия — материнский капитал, жилищный сертификат, ипотечную программу.

Шаг 3. Запрос на бэкенд

JavaScript отправляет параметры на Node. js-сервер по HTTPS. Прямого обращения к API «Движ» с фронтенда не происходит.

Шаг 4. Авторизация в «Движ»

Сервер авторизуется в «Движ» через GraphQL API и получает JWT-токен.

Шаг 5. Запрос в API «Движ»

Сервер отправляет параметры в API «Движ» с JWT-токеном. «Движ» подбирает подходящие ипотечные программы из актуальной базы.

Шаг 6. Обновление базы «Движ»

Параллельно «Движ» ежедневно запрашивает актуальные ставки у банков-партнёров — поэтому данные на сайте всегда свежие.

Шаг 7. Ответ на фронт

Сервер получает данные от «Движ» и возвращает их на сайт. Скрипт сортирует предложения, формирует карточки банков с указанием ставки и ежемесячного платежа, отображает результат.

Результат

Готовый ипотечный калькулятор для сайта dnscity.ru включает:
• Фильтр по параметрам: стоимость, взнос, срок, программа, жилищный сертификат, материнский капитал
• Поддержку льготных программ: Дальневосточная (от 2%), Семейная (от 6%), IT (от 6%), Военная (от 6%), Стандартная
• Описание каждой программы с условиями и ограничениями — покупатель понимает, подходит ли ему программа
• Актуальные предложения банков — карточки с названием банка, ставкой и ежемесячным платежом
• Автоматическую загрузку данных при открытии страницы
• Дизайн в брендбуке DNS Сити — шрифты, цвета, стиль карточек
• Мобильную адаптацию

Калькулятор работает в связке с формой заявки, после просмотра предложений пользователь может оставить контакт и получить персональную консультацию по ипотеке. Форма заявки интегрирована с amoCRM клиента, куда автоматически передаются данные потенциального клиента.
